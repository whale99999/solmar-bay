Solmar Bay is an original top-down 2D open-world crime game: explore a neon palm-city on foot and by car, steal cars, outrun the Solmar Bay police, run missions for fixer Carmen Sol, and build your rep. Pure Canvas 2D + WebAudio, zero dependencies, plays offline in desktop Chrome.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
